How the model works @if (crossSection()) {

Each day the model compares every {{ universe === 'crypto' ? 'coin' : 'stock' }} with the others on a few well-known effects: recent moves tend to partly reverse, longer trends tend to continue, calmer assets tend to do better than their risk suggests, and so on. Each input is ranked against the other assets that day, and a regression learns from history how much each one is worth and which way it points. It is tested on the most recent stretch of dates it never trained on, then retrained on everything for today's ranking. Crypto and stocks use separate models.
